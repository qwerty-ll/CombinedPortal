# ИВИТШ Хаб

Единая площадка студентов ИВИТШ КГУ (бывший CombinedPortal — гид первокурсника).
**Цель, решения, устройство кода и план по этапам — в `docs/ROADMAP.md`. Прочитай его перед работой
и обновляй раздел «Статус этапов» после каждого этапа.**

- Клиент: React 18 + Vite (`client/`). Сервер: FastAPI + SQLAlchemy + Alembic (`server/`).
- Проверки перед коммитом: `npm test` (pytest), `cd server && python -m app.db.migrate && alembic check`
  (любое изменение моделей — новая миграция), `npm run build`.
- Интерфейс по-русски, комментарии в коде — по-английски, коротко.
- Права проверяются на сервере. БД, `.env` и загруженные файлы в git не попадают.
