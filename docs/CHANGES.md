# Что нового в портале ИВИТШ

Сводка всех последних изменений (PR 1–5). Подробности — в `README.md`, `infrastructure/DEPLOYMENT_GUIDE.md`
и в сообщениях коммитов.

## Главное

- **ВИТШик знает портал**: отвечает по расписанию ЭИОС, аудиториям, преподавателям, FAQ и форуму,
  а на свободные вопросы — только по базе портала, без выдумок.
- **ВИТШик пишет документы**: объяснительная и заявление на пересдачу в Word или PDF, уже заполненные.
- **Где сейчас преподаватель**: «На паре в Б-305 до 11:40», «Свободна до 13:40».
- **Приложение на телефон**: портал ставится на главный экран и открывается как отдельное приложение.
- **Новый дизайн**, настоящие ФИО и группа из ЭИОС, запуск одной командой `docker compose up`.

## Для студента

**Вход и профиль**
- Вход через ЭИОС; ФИО и группа берутся из карточки студента ЭИОС, расписание сразу открывается на своей группе.
- Фото профиля не пропадает после перезагрузки и истечения сессии; можно вернуть фото из ЭИОС.
- Прогресс «Знакомства с порталом» считается по реальным действиям и хранится по аккаунту.

**Расписание**
- Прошедшие пары бледнеют, текущая выделена с обратным отсчётом, следующая — акцентом.
- Видно, для какой подгруппы пара; если у подгрупп разные пары в одно время — они стоят рядом колонками,
  у свободной подгруппы — «Нет пары». Замены помечены.
- Приветствие на главной: сколько пар сегодня, текущая или следующая пара с аудиторией.
- Никаких выдуманных пар: если ЭИОС не отвечает — последняя сохранённая копия с пометкой или честная ошибка.

**ВИТШик (чат)**
- Считает по расписанию: «где следующая пара», «что завтра», «когда философия», «а в пятницу?».
- Аудитории со схемой этажа, «где сейчас Киприна», ответы из FAQ и форума.
- Под ответом кнопки: аудитория на карте, расписание, карточка преподавателя, обсуждение на форуме.
- Гость может спрашивать про пары выбранной группы, не входя.

**Документы от ВИТШика**
- «Напиши объяснительную, вчера болел» → карточка с готовым документом: ФИО в родительном падеже, курс,
  группа, пропущенные пары и преподаватели из расписания, причина.
- «Хочу пересдать философию» → заявление на пересдачу: дисциплина, преподаватель, форма контроля.
- Поля правятся прямо в карточке; скачивание в Word (Times New Roman 14) или PDF.
- Адресат по умолчанию: «Директору Высшей ИТ-школы КГУ А. С. Борисову».

**Преподаватели**
- У каждого статус «сейчас» по расписанию ЭИОС и пары на сегодня в карточке.

**Телефон**
- Установка на главный экран (кнопка в профиле; для iPhone — подсказка про Safari).
- Работает только с интернетом: офлайн-режим убран, у кого он успел установиться, он удалится сам.
- Нужен HTTPS: по голому IP по HTTP установка недоступна.

**Дизайн**
- Новый интерфейс: светло-голубая навигация, цвет раздела на активном пункте, контраст AA везде.
- Нижняя панель вкладок на телефоне, поиск в FAQ, поиск аудитории на карте (`/map?room=Б-305`).

## Для администратора

- Блокировка и удаление пользователей, модерация форума (удалить ответ, отметить решение, закрепить вопрос).
- Истёкшая сессия выходит из аккаунта, а не показывает пустую панель.
- Вход администратора — только из `ADMIN_USERNAME` / `ADMIN_PASSWORD` в `.env`, демо-данных больше нет.

## ВИТШик и GigaChat: как устроено

- **Точные факты** (пары, время, аудитории, где преподаватель) считаются из данных и не проходят через модель.
- **GigaChat** только пересказывает найденное в FAQ, на форуме и в базе знаний, и только для вошедших.
- **Строго по базе**: нет ответа в базе — модель не вызывается; вопрос не по теме — «не нашёл»;
  ответ модели с числом, почтой, ссылкой или @ником, которых нет в найденном тексте, заменяется самим текстом;
  просьбы «забудь правила» не работают.
- **Один поток**: ключ физлица обслуживает один запрос за раз. Вопросы ждут очереди не дольше 6 с,
  дальше — ответ из базы без пересказа. На весь вызов 15 с; после ошибки 429 или 5xx — пауза 30 с.
- **Чаты не смешиваются**: каждый запрос несёт только свою историю, сервер ничего не хранит между запросами.
  Ответ, пришедший после завершения чата, отбрасывается; при смене аккаунта чат начинается заново.
- Проверка реальными запросами (ключ и токен не печатаются):
  `docker compose exec portal python -m app.services.gigachat_check`

## Безопасность

- JWT только в httpOnly-cookie, проверка CSRF-заголовка, bcrypt, `SECRET_KEY` не короче 32 символов.
- Аккаунт привязан к ID в ЭИОС, лимиты попыток входа, блокировка пользователей.
- nginx: HTTPS с редиректом, строгий CSP, заголовки безопасности на всех путях (не теряются в location).
- Проверка TLS для GigaChat не отключается — используется сертификат Минцифры.
- Бэкенд в контейнере работает не от root; миграции Alembic применяются при старте.

## Настройки `.env`

| Переменная | Зачем |
|---|---|
| `SECRET_KEY` | подпись сессий (в одном контейнере генерируется сам) |
| `ADMIN_USERNAME`, `ADMIN_PASSWORD` | вход в панель управления |
| `GIGACHAT_AUTH_KEY` | ключ GigaChat; без него ВИТШик отвечает только данными портала |
| `GIGACHAT_SCOPE` | `GIGACHAT_API_PERS` для физлица |
| `GIGACHAT_MODEL` | по умолчанию `GigaChat-2` |
| `GIGACHAT_MAX_STREAMS` | одновременных запросов: 1 для физлица, 10 для юрлица |
| `GIGACHAT_CA_BUNDLE` | путь к сертификату Минцифры; в Docker не нужен, если файл лежит в `infrastructure/gigachat-ca/` |
| `DOCUMENT_ADDRESSEE_TITLE`, `DOCUMENT_ADDRESSEE_NAME` | адресат документов (дательный падеж); `-` — пустая строка |

## Что сделать после обновления

1. `git checkout main && git pull` — заодно удалит старый `infrastructure/nginx.conf`.
2. Перевыпустить ключ GigaChat и секреты: старые остались в истории git (шаг 0 в `DEPLOYMENT_GUIDE.md`).
3. Заполнить `.env` (таблица выше).
4. Положить сертификат Минцифры в `infrastructure/gigachat-ca/russian_trusted_root_ca.pem`.
5. Пересобрать: `docker compose up --build` (новые зависимости: python-docx, reportlab, pytrovich).
6. Проверить GigaChat командой `gigachat_check` (см. выше).
7. Для установки на телефон открыть портал по HTTPS.

## Новое в API

| Метод | Что делает |
|---|---|
| `GET /api/v1/schedule/teachers/today` | пары преподавателей портала на сегодня |
| `GET /api/v1/documents/pairs?date=` | пары студента за день (для объяснительной) |
| `POST /api/v1/documents/explanatory?format=docx\|pdf` | объяснительная |
| `POST /api/v1/documents/retake?format=docx\|pdf` | заявление на пересдачу |
| `POST /api/v1/chat` | ответ теперь с кнопками `actions` и черновиком `document` |

Миграции базы: `0002` блокировка и источник входа, `0003` фото из ЭИОС, `0004` ID группы в ЭИОС.
